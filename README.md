# A la pêche aux phish

[A la pêche aux phish](https://lattice-walker.github.io/A-la-peche-aux-phish/) est un jeu qui apprend aux utilisateurs à repérer les emails de phishing. Il a été conçu pour aider les joueurs à reconnaître le phishing à travers des exercices pratiques, dans un cadre sécurisé où les erreurs sont une occasion d'apprentissage, et non une menace réelle.

D'autres jeux de sensibilisation existent déjà. Celui-ci se distingue sur deux points.

Le premier est l'interface. Elle reproduit celle de Gmail, que de nombreux joueurs utilisent quotidiennement, de sorte que les emails apparaissent tels qu'ils le feraient dans une véritable boîte de réception, avec les mêmes repères visuels.

Le second est la personnalisation. Le jeu utilise le prénom, le nom et l'entreprise du joueur, de sorte que les messages s'adressent directement à lui, comme le ferait un attaquant après avoir effectué des recherches préalables.

Un email générique est facile à repérer. Un email qui connaît votre nom et votre employeur est plus crédible, et c'est ce type d'email sur lequel les gens cliquent. Le jeu place le joueur dans cette situation afin qu'il prenne l'habitude de s'arrêter avant d'ouvrir un lien ou une pièce jointe.

Les systèmes internes du jeu sont originaux, tandis que l'interface utilisateur a été développée avec l'aide d'outils basés sur l'IA.
